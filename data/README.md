# CIFAR-100 dataset

Local archive: `data/raw/cifar-100-python.tar.gz` (ignored by Git).
Complete 50,000-image train split and 10,000-image test split are available.
Archive and both split files passed torchvision's official MD5 checks.

The original host download was truncated. A byte-equivalent archive was retrieved
from a Hugging Face mirror and accepted only after official checksum verification.
See `manifest.json` for both source URLs, checksums and file provenance, and
`reports/incidents/INC_001_dataset_download.md` for the resolved preflight incident.
